# IPL Performance Analysis Dashboard

## Overview

An interactive Power BI dashboard developed to analyze IPL performance and uncover meaningful insights across teams, players, batting, bowling, venues, and match-level performance.

The project focuses on transforming cricket data into interactive visual insights using Power BI, Power Query, and DAX.

## Project Highlights

- Built a 3-page interactive Power BI dashboard.
- Analyzed 278K+ records across 64 attributes.
- Explored team and player performance across IPL seasons.
- Analyzed batting, bowling, boundaries, runs, venues, and match outcomes.
- Created KPI-driven analysis using DAX measures.
- Used interactive slicers, maps, and analytical visualizations for exploration.

## Tools & Technologies

## Dashboard Analysis

### Team Performance

Comparative analysis of team-level performance and scoring trends across seasons.

### Player Performance

Analysis of individual player contributions and performance patterns.

### Batting & Scoring Analysis

Exploration of runs, boundaries, scoring patterns, and run contribution.

### Bowling & Wicket Analysis

Analysis of bowling performance, wickets, and dismissal-related patterns.

### Venue Analysis

Exploration of performance across different IPL venues and locations.

### Match Analysis

Analysis of match-level outcomes and performance trends.

## Dashboard Features

- Interactive slicers and filters
- KPI cards
- Comparative performance analysis
- Player insights
- Venue and location analysis
- Run and boundary analysis
- Season-wise exploration
- Interactive visualizations
